2026 추수감사 특별새벽부흥회 행사 전용 홈페이지
=================================================

1. 홈페이지 미리보기
   index.html 파일을 더블클릭하면 브라우저에서 열립니다.
   인터넷에 연결하면 구글 폰트와 구글 지도가 함께 표시됩니다.

2. 수정하는 방법
   content.js 파일만 수정하면 날짜별 제목, 본문, 시간, 유튜브 링크가 바뀝니다.
   각 날짜의 youtubeUrl: '' 에 실제 유튜브 동영상 주소를 입력하면
   LIVE & REPLAY 영상 영역에 동영상이 자동으로 표시됩니다.
   아직 영상 URL이 없으므로 현재는 '공개 예정'으로 나타납니다.

3. 디자인/이미지 변경
   style.css: 색상, 글자 크기, 간격 등 디자인
   index.html: 메뉴, 페이지 문구 및 화면 구성
   assets/pastor-han.png: 제공하신 기존 포스터에서 사진 부분을 잘라 사용함
   assets/event-poster.jpg: 예전 행사 포스터를 별도 저장용 이미지로 포함
   두 사진은 AI로 얼굴을 새로 생성하거나 변형하지 않았습니다.

4. 기능
   - PC/모바일 반응형 화면과 모바일 메뉴
   - 날짜별 말씀 일정 필터
   - 영상 URL이 설정되면 YouTube 임베드 자동 생성
   - 집회일까지 실시간 카운트다운
   - 전체 6일 일정 .ics 캘린더 저장 (종료 시각은 임시로 1시간 처리)
   - 구글 지도, 길찾기, 주소 복사, 링크 공유
   - 행사 포스터 저장
   - 목차 클릭 시 해당 섹션 이동

5. Vercel 배포
   A. https://github.com 에 새 저장소를 만들고 이 폴더 안 파일들을 업로드
   B. https://vercel.com 에 로그인 -> Add New -> Project -> GitHub 연결
   C. 저장소 선택 -> Deploy
   D. 이후 GitHub의 content.js 파일을 편집/저장하면 Vercel이 자동 재배포합니다.

   참고: Vercel Hobby 플랜의 개인·비상업적 이용 제한을 확인하세요.
   교회 공식 운영에는 사용 조건에 맞는 플랜을 선택해야 합니다.

6. 온라인 영상 URL
   현재 '은혜한인교회 인터넷방송' 버튼은 공식 홈페이지 https://gracemi.com/ 로 연결됩니다.
   향후 실제 라이브 또는 유튜브 전용 주소가 확정되면
   content.js의 livestreamUrl 값을 변경하세요.

7. 배포 전 확인
   - 일정/강사/주소/전화번호 최종 검토
   - 새 영상 공개 때 youtubeUrl 입력
   - 카카오톡 SNS 미리보기의 OG 이미지가 필요한 경우
     index.html 속성 og:image 를 배포된 절대 URL로 변경하는 것을 권장합니다.
   - 실제 집회 종료 시각이 별도로 알려지면 캘린더 기능 종료 시간을 수정하세요.
